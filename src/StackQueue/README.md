Stacks And Queue

Fundamental data types.
・Value: collection of objects.
・Operations: insert, remove, iterate, test if empty.
・Intent is clear when we insert.
・Which item do we remove?

Stack. Examine the item most recently added.
LIFO = "last in first out"

Queue. Examine the item least recently added.
FIFO = "first in first out"


*** Modular Programing ***

Client: program using operations defined in interface.
Implementation: actual code implementing operations.
Interface: description of data type, basic operations.



Examples :

The Queue: The "Line at the Checkout" (FIFO)
Think of standing in a line at a store. The first person to get in line is the first person to get served.

The Stack: The "Cafeteria Tray" (LIFO)
Think of a stack of cafeteria trays. You put a new tray on the top, and when you need one, you take it from the top. You never pull a tray from the bottom.

Stack = "Undo" or "Back" or "Nested" (The most recent thing matters).

Queue = "Waiting Line" or "Buffer" (The first thing to arrive is the first thing to process).
